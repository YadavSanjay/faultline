# CLAUDE.md — `src/pricer`

QuantLib 1.42.1 pricer for the 38-trade / 6-asset-class / 11-instrument book, plus risk,
portfolio-construction (sizing), governance, observability, and a calculation-lineage layer.
Operator guide: [../../docs/guides/pricer_guide.md](../../docs/guides/pricer_guide.md) ·
[risk_guide.md](../../docs/guides/risk_guide.md). Per-trade methodology:
[../../docs/pricing/](../../docs/pricing/README.md). Design:
[../../docs/design/AITrade_quantlib_pipeline_design.md](../../docs/design/AITrade_quantlib_pipeline_design.md).

## Architecture — 3 layers + engine

- **`input/`** — pure domain objects, **no QuantLib import** (per-asset instrument dataclasses;
  each Trade declares `market_data_requirements(ctx)`). Mockable.
- **`loader/`** — CSV → domain adapters (one per asset class) + `snapshot.py` (immutable,
  content-addressed `MarketDataSnapshot`), `staleness.py`, `schema.py` (required-column enforcement).
- **`ql/`** — the **only** layer that imports QuantLib. `ql/factory.get_pricer(trade)` dispatches by
  asset class to per-asset `pricer_factory.py` + pricers. `ql/common/` has curve/vol builders,
  `curve_cache.py`, `base_pricer.py` (sets process-global `ql.Settings.evaluationDate`).
- **`engine.py`** — `PricingEngine.price(trade, ctx)` (pure) / `price_portfolio(trades, ctx)`
  (fault-isolated, shared curve cache). "**One engine, two drivers**": batch `runner.py` and FastAPI
  `service.py` both call it.

Layered on top: `portfolio/` (books + versioning), `risk/`, `output/` (Parquet result_store),
`obs/`, `governance/`, `sizing/`. Config: `config.py` + `config_models.py` (pydantic) + `settings.py`
(`PRICER_*` env). `lineage.py` = ENG-1 explain pass.

## Entry points (from repo root, py312)

```powershell
python -m src.pricer.runner            # --asset-class --trade --valuation-date --valuation-type --workers --book
python -m src.pricer.risk_runner       # --no-full-reval-var (full-reval is ON by default) --no-var --no-scenarios --no-backtest --book --explain SCEN
python -m src.pricer.lineage_runner    # --trade --asset-class --book  → data/pricer/lineage/<date>/<id>.json
python -m src.pricer.governance_runner # exits 0/1; golden PV + IPV + model-inventory  (NO --book)
python -m src.pricer.sizing.sizing_runner  # --profile  → regenerates portfolio_{balanced,core,aggressive,risky}.json
conda run --no-capture-output -n py312 uvicorn src.pricer.service:app --port 8080   # optional FastAPI facade
```

Outputs under `data/pricer/`: `PV/<class>/<id>/<date>.json`, `store/results` (Parquet+DuckDB),
`store/runs`, `store/spans`, `snapshots/`, `risk/<date>/`, `lineage/<date>/`, `governance/<date>/`,
`sizing/<date>/`.

## Risk (`src/pricer/risk/`)

`risk_runner` produces one JSON with: sensitivities/Greeks (`sensitivities.py`, `bumps.py`), named
stress scenarios (`scenarios.py`), sensitivity VaR/ES with delta-gamma + Filtered HS + Stressed VaR
+ parametric x-check + component-ES (`var.py`), full-reval VaR/ES (`historical_var.py`,
`factor_history.py`), backtest (Kupiec + **Christoffersen** + Basel, `backtest.py`), limits
(`limits.py`), P&L explain + carry/theta (`pnl_explain.py`), JTD/IDR (`jtd.py`). **39** VaR factors.
Per-issuer credit factors `credit:ORCL` / `credit:META` (`issuer_credit.py`, config
`risk.hist_var.issuer_credit`) come from the DTCC single-name 5Y prints, backfilled before the DTCC
history from IG OAS × the issuer/IG level ratio; `bumps.shift_credit_issuers` applies them, so an issuer
key overrides `credit` for that issuer's bond and CDS curves. The other issuers and CDX stay on `credit`.
The aligned factor panel (`FactorHistory._aligned_moves`, used by full-reval VaR and scenariogen's Σ)
runs `carry_short_gaps` before its `dropna`: a date stays if ≥ `risk.panel_min_coverage` (0.75) of
factors observed it, and a factor's interior gap of ≤ `risk.panel_max_gap_days` (3) rows is a 0.0
move (FRED Treasury holes, BoJ holidays). `panel_max_gap_days = 0` restores the plain inner join. The
carried cells per factor in the window are in `FactorHistory.panel_carried_cells` and the full-reval
VaR result's `panel_carried_cells` (spec `docs/specs/panel-gap-carry.md`). The sensitivity VaR family
(`VarEngine`: Δγ headline, decomposition, parametric, FHS, stressed) replays **the same dates**:
`var.align_to_window` puts its own per-factor P&L columns on `FactorHistory.aligned_panel`'s window
(last `lookback` dates; all aligned history for stressed), carrying the same short gaps, so Δγ and
full-reval VaR compare like with like. Both results carry `dates` (spec `docs/specs/var-panel-window.md`).

## Conventions

- **Books are selectable.** `portfolio.json` = active default (core, since the 2026-07-26 rebalance —
  docs/design/portfolio_rebalance_review.md); base = `portfolio_base.json`; variants
  `portfolio_{balanced,core,aggressive,risky}.json` regenerated by the sizing runner. Select via
  `--book` / `PRICER_BOOK` / loader `book=` (runner, risk_runner, lineage_runner, scenariogen.runner
  support `--book`; governance_runner does not).
- **Curve cache** (`ql/common/curve_cache.py`) is `contextvars`-scoped and process-local — active only
  inside `with curve_cache():`. `ql.Settings.evaluationDate` is process-global, so parallelism is
  process-level (`--workers`, chunked by `(asset_class, trade_id)` for cache locality).
- **Config planes:** model params in `configs/pricer/pricer_config.json` (pydantic-validated, optional
  `pricer_config.<PRICER_ENV>.json` overlay); runtime ops via `PRICER_*` env (`settings.py`), incl.
  `PRICER_DEPLOY_MODE`/`PRICER_DATA_URI` (dual-mode local-FS|S3 — all `data/` I/O goes through
  `src/common/storage`, never raw `root/"data"/…` paths) and `PRICER_API_KEY` (the `X-API-Key`
  gate on `service.py`, no-op when unset). See [../../docs/guides/deployment_guide.md](../../docs/guides/deployment_guide.md).
- Lint/type/test: `ruff check src/pricer`, `mypy`, `pytest tests/pricer` (mocked + `*_real_data` that
  need `data/marketdata/`).

## Gotchas

- **Golden PVs** are pinned to the portfolio default (2026-10-06, core), so a default
  `governance_runner` passes. Rebaseline `golden_pvs.json` **only when asked** (record
  `rebaseline_history`, and move `tests/pricer/test_governance.py::VDATE` in lockstep). The
  `snapshot_id` fingerprints the on-disk market-data files, not the valuation date.
- The pricing-enhancement program (A1–C1) is **delivered** — don't treat
  `AITrade_pricing_enhancement_design.md` as unbuilt roadmap.
- All 6 asset classes have trade builders (`portfolio_loader._BUILDERS`) and pricers — no "rates only".
